# LAB1 – Swift Basics

**What this lab is about:** the first steps in Swift: storing values, working with
different kinds of data, and handling "maybe there is no value" cases.

## What's inside

| File | Topic |
|------|-------|
| `Exercise01.swift` | Constants (`let`) and variables (`var`) |
| `Exercise02.swift` | Data types and type inference |
| `Exercise03.swift` | Type conversion and arithmetic operators |
| `Exercise04.swift` | Comparison operators (`==`, `!=`, `>` ...) |
| `Exercise05.swift` | Strings and joining text |
| `Exercise06.swift` | Optionals (`String?`) and `nil` |
| `FinalChallenge.swift` | Student result and eligibility calculation |
| `screenshots/` | Output of the exercises and the final challenge |

**How to run:** open any `.swift` file in Xcode (or a Swift Playground) and run it to see the printed output.
