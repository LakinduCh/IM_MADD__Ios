# SE4041 Practical 02 – Collections and Control Flow

**What this lab is about:** grouping data together (arrays, sets, dictionaries) and
making decisions or repeating work (`if`, `switch`, loops).

## What's inside

| File | Topic |
|------|-------|
| `Exercise01.swift` | Arrays of marks |
| `Exercise02.swift` | Sets (unique values, insert/remove) |
| `Exercise03.swift` | Dictionaries (name -> mark) |
| `Exercise04.swift` | `if / else if / else` |
| `Exercise05.swift` | `switch` on a grade |
| `Exercise06.swift` | `for` loops and ranges |
| `FinalChallenge.swift` | Process a dictionary of student marks |
| `screenshots/` | Output screenshots (to be added) |

**How to run:** open a `.swift` file in Xcode (or a Swift Playground) and run it.
