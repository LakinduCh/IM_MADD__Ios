# SE4041 Practical 03 – Functions, Closures and Enums

**What this lab is about:** reusable code (functions), short inline code (closures such as
`filter` and `reduce`), and fixed sets of choices (enumerations).

## What's inside

| File | Topic |
|------|-------|
| `Exercise01.swift` | Basic functions |
| `Exercise02.swift` | `guard` and early exit with optionals |
| `Exercise03.swift` | Functions returning a tuple (min, max, average) |
| `Exercise04.swift` | Closures: `filter`, `map`, `reduce` |
| `Exercise05.swift` | Enumerations |
| `Exercise06.swift` | Enums with raw values |
| `FinalChallenge.swift` | Grade enum used to grade students |
| `screenshots/` | Output screenshots (to be added) |

**How to run:** open a `.swift` file in Xcode (or a Swift Playground) and run it.
